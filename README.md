# Andromeda Solutions

A fast, responsive static agency website for Andromeda Solutions in Jalandhar, Punjab.

## Local preview

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Deployment

The site is plain HTML, CSS and JavaScript and can be published directly with GitHub Pages from the repository's `main` branch and root directory.
